# Developer Embed & Export Guide

**Chord Draft Diagram Make by Ray Foo** provides multiple export formats so music educators and web developers can drop crisp guitar chord diagrams into websites, Markdown docs, or classroom worksheets.

---

## Export Formats

1. **SVG Vector (`.svg`)**
   - Resolution-independent vector graphic generated by `src/utils/svgGenerator.ts`.
   - Suitable for print handouts, Keynote/Slides, Illustrator, Figma, or inline HTML.
2. **High-DPI PNG (`.png`)**
   - Rasterized at `2×`, `3×`, or `4×` scale via an offscreen HTML5 Canvas.
   - Supports optional transparent backgrounds for overlaying onto dark or colored slides.
3. **JSON Chord Spec (`.json`)**
   - Structured data payload containing title, detected chord name, interval formula, base fret, fret count, MIDI tuning array, string-by-string frets/fingers/notes, and barres.
4. **Vanilla JS Embed Widget (`<div class="fretdraft-chord">`)**
   - Self-contained HTML + Vanilla JS snippet with zero external dependencies.

---

## Using the Vanilla JS Widget

Copy the generated snippet from the **Developer Embed** view (or the **Export / Embed** tab inside **Diagram Studio**).

### Example Markup

```html
<div
  class="fretdraft-chord"
  data-title="C"
  data-frets="x,3,2,0,1,0"
  data-fingers=",3,2,,1,"
  data-base-fret="1"
  data-fret-count="5"
  data-barres=""
  data-handedness="right"
  data-accent="#0284C7"
  data-bg="#FFFFFF"
  data-ink="#0F172A"
></div>
```

Include the generated `<script>` tag once at the bottom of your page. It scans `document.querySelectorAll(".fretdraft-chord")` and renders every diagram automatically.

---

## Supported `data-*` Attributes

| Attribute | Example | Description |
| :--- | :--- | :--- |
| `data-title` | `"Am7"` | Heading rendered above the diagram |
| `data-frets` | `"x,0,2,0,1,0"` | Six comma-separated frets from 6th string (low) to 1st string (high); use `x` for muted and `0` for open |
| `data-fingers` | `",,2,,1,"` | Six comma-separated finger labels (`1`, `2`, `3`, `4`, `T`, or empty) |
| `data-base-fret` | `"1"` | Starting fret number (`1` draws a nut bar; `> 1` renders a fret label like `3fr`) |
| `data-fret-count` | `"5"` | Number of fret rows drawn (`4`, `5`, or `6`) |
| `data-barres` | `"1:4-5"` | Comma-separated barre specs in `fret:fromString-toString` format (`0` = 6th string, `5` = 1st string) |
| `data-handedness` | `"right"` | `"right"` (standard) or `"left"` (mirrored) |
| `data-accent` | `"#0284C7"` | Fill color for finger dots and barre bars |
| `data-bg` | `"#FFFFFF"` | Background color of the SVG card |
| `data-ink` | `"#0F172A"` | Text and string line ink color |

---

## Multiple Diagrams on One Page

Place as many `<div class="fretdraft-chord" ...></div>` elements as needed in your article or lesson page, and include the `<script>` block once after them. Each element tracks `data-rendered="1"` so re-running the script will not duplicate SVGs.
